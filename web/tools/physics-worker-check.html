Physics worker check

Steps the same cars on the same track in the page and in a Web Worker (js/PhysicsWorker.js) and checks that both give the same numbers, every frame (PHYSICS-WORKER.md). Then it times the physics: in the page, in one worker, and in a worker per car (side by side, on more cores). Open it on a phone to see what a worker gains there.
